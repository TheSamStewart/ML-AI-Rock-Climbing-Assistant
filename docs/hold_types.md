# Hold types

The hold types the app recognises, and how to tell them apart. It's used for labelling, the classifier prompt and the app's labels.

**Keep this up to date:** any change to hold classification (types, names, rules) updates this table in the same change.

| Type | How to identify it |
|---|---|
| Jug | Deep, positive hold you can wrap your whole hand round. Includes buckets and horns. |
| Crimp | Small, hand-sized edge that only takes the finger pads. |
| Rail | A long edge you can move your hands along, such as the edge of a roof. Covers "edges". |
| Sloper | Rounded, with no positive edge. Held by friction and an open hand. |
| Pinch | Gripped by squeezing between thumb and fingers. |
| Pocket | A hole that takes 1–3 fingers. |
| Macro | A very large hold, usually fibreglass, gripped directly, often in several places. It's a hold, not a volume. |
| Jib | A tiny screw-on chip, only usable as a foot. |
| Volume | A large shape bolted to the wall, with other holds bolted onto it. Not gripped as a hold itself. |
| Other | Anything else, or unclear. |
| ? (unsure) | The classifier isn't confident. No type is shown. |

**Macro vs volume:** if you would grip it, it's a macro. If holds are bolted onto it and you climb on those, it's a volume.

**Covered elsewhere, not types:** which way a hold faces (undercling, sidepull, gaston: #44); positive or incut (#45); size (#46); whether it's a foothold on this route (#47).
